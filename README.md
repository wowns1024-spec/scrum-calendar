# 스크럼 캘린더

팀이 함께 쓰는 타공판 스크럼 보드입니다. 날짜를 열면 팀원들이 붙여 놓은 메모가 한 판에 모입니다.

## 쓰는 방법

1. 아이디 · 비밀번호 · 닉네임으로 가입합니다.
2. 달력에서 날짜를 클릭하면 그 날짜의 타공판이 열립니다.
3. 오른쪽 위 `+` 버튼으로 어제 한 작업 · 오늘 할 작업 · 막힌 점 · 이벤트를 적습니다.
4. 저장하면 메모가 판에 박힙니다. **한 날짜에 한 사람당 메모는 한 장**이고, 다시 저장하면 그 메모의 내용이 바뀝니다.

## 팀원 초대

오른쪽 위 링크 버튼을 누르면 초대 링크가 복사됩니다. 링크를 받은 사람이 가입하면 같은 달력을 함께 씁니다.
누가 저장하든 다른 사람 화면에 새로고침 없이 바로 나타납니다.

## 그 밖의 기능

- 오른쪽 위 돋보기: 키워드로 달력 전체의 메모를 찾습니다.
- 페이지 맨 아래: 전체 기록을 JSON으로 내보내거나 가져옵니다.

## 구성

- `index.html` — HTML · CSS · JavaScript가 모두 들어 있는 단일 파일입니다.
- 저장소는 Firebase Firestore를 사용합니다. `index.html` 위쪽 `FIREBASE_CONFIG`에 프로젝트 설정이 들어갑니다.
- `firebase.json`, `.firebaserc` — Firebase Hosting으로 배포할 때 쓰는 설정입니다.

## 주의

계정 확인이 브라우저에서 이뤄지는 구조라 실제 서비스 수준의 보안은 아닙니다.
**다른 곳에서 쓰는 비밀번호는 사용하지 마세요.** 팀 내부용으로만 쓰는 것을 전제로 만들었습니다.
